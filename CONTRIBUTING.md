# Contributing to SAMBA

Thank you for your interest in contributing to SAMBA.

## Partners
This project is led by INS Mozambique in collaboration with:
- Fiocruz / FIOTEC (Brazil)
- IPO Lisboa (Portugal)
- UCM (Mozambique)

## How to contribute

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Commit your changes: `git commit -m "feat: description"`
4. Push to the branch: `git push origin feature/your-feature`
5. Open a Pull Request

## Commit convention
- `feat:` new feature
- `fix:` bug fix
- `docs:` documentation
- `chore:` maintenance
- `model:` AI model updates
- `data:` dataset updates
