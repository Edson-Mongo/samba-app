# SAMBA Clinical Protocol v0.1

## Study title
SAMBA: Validation of an AI-powered blood smear analysis app for acute
leukemia screening in resource-limited settings — Mozambique

## Design
Prospective diagnostic accuracy study (STARD 2015)

## Index test
SAMBA App (morphological analysis + SAMBA Risk Score)

## Reference standard
Flow cytometry immunophenotyping (BD FACSLyric DxFlex BC, INS)

## Target condition
Acute leukaemia (ALL-B, ALL-T, AML) confirmed by flow cytometry

## Participants
- Consecutive patients with clinical suspicion of haematological malignancy
- Age: all ages
- Setting: Hospital Central de Maputo, HCN, INS
- Sample size: n = 50 (pilot study)

## Blinding
SAMBA App result recorded BEFORE flow cytometry result is known

## Primary endpoints
- Sensitivity for blast detection ≥ 5%
- Specificity
- AUC (ROC analysis)
- 95% CI by Wilson method

## Ethics
Submission to CNBS (Comité Nacional de Bioética de Saúde), Mozambique
